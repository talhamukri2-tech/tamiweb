# tamiweb portfolio — GitHub Pages version

## Folder structure

- `index.html` — complete website content and SEO metadata
- `css/style.css` — all styling and responsive layouts
- `javascript/script.js` — navigation, animations and form interaction
- `assets/tam-mascot.webp` — optimized Tam mascot image

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and folder from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The contact form is currently a front-end demonstration. Add your email or
WhatsApp details before connecting it to a form service.
